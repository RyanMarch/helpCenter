Getting Started

Welcome to Icon Studio! This guide will help you understand the interface and build your very first customized icon from scratch.

Icon Studio provides a real-time playground where you can customize layouts, shapes, gradients, and badges to design assets for websites, mobile applications, or presentations.

Workspace Layout

The workspace is split into two primary areas:

  • The Preview Canvas: Displays your icon layout dynamically in real time. It supports various device scales and viewport simulations.
  • The Configuration Sidebar: Contains panels for configuring the base layer, style properties, gradients, borders, and badge overlays.

Creating Your First Icon

To begin design customization, navigate to the sidebar options:

  1. Choose a Base Layer: Choose between an Icon (using the built-in library), custom Text, or an uploaded Image.
  2. Adjust Canvas Styles: Select background properties like solid colors or multi-color gradients. You can also customize border radius, padding, and drop shadows.
  3. Configure Badges: Optionally add a notification badge to the corner of your icon for application layouts.
